PlayArena Mobile Sports Demo
============================

এটি একটি মোবাইল-ফ্রেন্ডলি STATIC DEMO। কেবল কাল্পনিক ম্যাচ, অডস এবং ভার্চুয়াল ক্রেডিট রয়েছে। কোনো বাস্তব টাকা, ডিপোজিট, উইথড্র, বাস্তব বেটিং, লগইন বা ব্যাকএন্ড নেই। এটি 1xBet-এর অফিসিয়াল পণ্য নয়।

ফোন দিয়ে GitHub Pages-এ প্রকাশ:
1. https://github.com খুলে লগইন করুন।
2. New repository তৈরি করুন; Public নির্বাচন করুন।
3. ZIP খুলে ভেতরের index.html এবং README-BN.txt ফাইল repository-র root-এ আপলোড করুন (ZIP ফাইলটি নিজে আপলোড করলেই সাইট চালু হবে না)।
4. Settings > Pages খুলুন। Build and deployment-এ Deploy from a branch নির্বাচন করুন।
5. Branch: main এবং folder: /(root) নির্বাচন করে Save চাপুন।
6. কিছুক্ষণ পরে Pages-এর উপরে দেখানো URL খুলুন।

নোট: এই ডেমোতে সবকিছু ব্রাউজারের মধ্যেই চলে। পেজ রিফ্রেশ করলে ভার্চুয়াল ব্যালেন্স রিসেট হতে পারে। এটি মূল ZIP-এর ব্যাকএন্ডকে চালু করে না এবং বাস্তব বেটিং সিস্টেম নয়।
